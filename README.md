Codebase for jhuparkinsonspals.jonathantzhang.com, the website of the Johns Hopkins University of Parkinson's Pals, an organization dedicated to reducing loneliness in individuals with Parkinson's and other neurodegenerative diseases, by facilitating intergenerational connections between patients and college students through regular socialization. 

Open source for transparency, forked from https://github.com/smartergiving/free-nonprofit-starter-website
